# AssetVault - 个人数字资产管理器 (Python + PyQt6 版)

离线运行的 Windows 桌面应用，用于管理序列号、密码、API 密钥、SSL 证书、订阅服务、硬件设备凭证、数字钱包、软件许可证等全场景数字资产。

## 功能特性

- 🔐 **AES-256-GCM 加密** - 所有敏感数据本地加密存储
- 🧩 **8 类内置资产模板** - 序列号 / 密码 / API 密钥 / SSL 证书域名 / 订阅服务 / 硬件设备 / 数字钱包 / 软件许可证，各有专属字段
- 🛠️ **资产模板引擎** - 自定义模板（文本/密码/多行/日期/下拉/数字/附件字段），支持独立到期提醒规则
- 📊 **上下文感知仪表盘** - 核心状态卡（总数/正常/紧张/已用完，点击直接过滤表格）+ 按选中类型自动切换的二级动态指标（弱密码/重复密码/30天内到期/自动续期等），无关指标自动隐藏
- 🏷️ **状态标签栏** - 顶部独立药丸标签（全部/正常/紧张/已用完/将到期，实时计数），与左侧类型导航物理分离
- 🎯 **高级筛选** - 按类型、有效期范围（7天/30天/已过期/永久）、标签组合（AND 匹配）叠加筛选，一键清除
- 🏷️ **资产标签** - 逗号分隔多标签，支持组合查询与全文搜索，CSV/Excel/JSON 导出均保留
- 🗂️ **表格体验** - 账号列悬停显示完整内容并一键复制（掩码模式下也复制真实明文）、用量进度条（剩余量变色）、有效期相对时间（临期自动变色）、行悬停高亮、行内操作列
- 🎨 **色彩语义统一** - 正常=绿、紧张/将到期=橙、已用完/过期=红，全站一致
- 📭 **空状态引导** - 区分「暂无数据」与「筛选无结果」，提供直达新增/清除筛选按钮
- 👁️ **明文/掩码切换** - 账号与序列号默认明文显示，可一键切换为掩码
- 🗑️ **回收站** - 软删除机制，支持恢复和彻底删除
- 📤 **导入导出** - 支持 JSON 备份恢复、CSV 与 Excel（.xlsx）表格导出
- 📋 **快捷复制** - 右键按列复制（账号/密码/序列号/有效期/网址等）
- ⚙️ **设置菜单** - 修改主密码（全量数据自动重加密）、资产模板管理
- 🎲 **密码生成器** - 内置强密码生成工具

> 注意：导出文件（JSON / Excel）中账号、序列号、密码均为**明文**，请妥善保管导出文件。

## 技术栈

- **前端**: PyQt6 + 纯 CSS 样式（按设计稿精确实现）
- **后端**: Python 3.10+
- **数据库**: SQLite（本地文件）
- **加密**: Argon2id + AES-256-GCM (cryptography 库)

## 快速开始

### 环境要求

- Python 3.10 或更高版本
- Windows 10/11

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行

```bash
python main.py
```

### 打包为 .exe

```bash
pip install pyinstaller
python build.py
```

打包完成后，可执行文件位于 `dist/AssetVault.exe`。

## 手动打包命令

```bash
pyinstaller --name AssetVault --windowed --onefile --noconfirm --clean main.py
```

## 数据存储

- 数据库文件：`vault.db`（与 AssetVault.exe 同目录；源码运行时与 main.py 同目录）
- 加密方式：Argon2id 派生密钥 + AES-256-GCM 加密
- 首次运行需设置主密码

## 安全说明

- 主密码仅用于本地派生加密密钥，**不会上传到任何服务器**
- 所有数据存储在本地 SQLite 数据库中
- 敏感字段（密码、序列号）使用 AES-256-GCM 加密
- 密钥通过 Argon2id（内存困难型哈希）派生，抵抗暴力破解
